# Undangan pernikahan — Alya & Raka

Website satu halaman dengan sampul interaktif, transisi pembuka, animasi saat menggulir, dan desain responsif. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa proses build.

## Membuka website

Buka `index.html` di browser. Foto contoh tersedia secara lokal di `assets/couple.jpg`. Font Google memerlukan internet; font bawaan perangkat digunakan jika tidak tersedia.

## Mengganti informasi

### Musik latar

File musik ada di `assets/perfect-ed-sheeran.mp3`. Tombol **Buka Undangan** sekaligus membuka undangan dan memutar musik yang berulang otomatis. Tidak ada tombol musik terpisah. Jika file tidak tersedia, undangan tetap dapat dibuka.

- **Nama, ucapan, dan alamat:** edit `index.html`, termasuk judul dan deskripsi pada bagian `<head>`.
- **Foto:** ganti `assets/couple.jpg` dengan foto pasangan, dan sesuaikan teks `alt` di `index.html`.
- **Warna dan font:** edit variabel di awal `styles.css`.
- **Animasi pembuka:** edit `script.js`. Preferensi pengurangan gerak dari perangkat sudah didukung.

Semua nama dan alamat adalah contoh. Peta merupakan ilustrasi, bukan lokasi sebenarnya. Ganti ilustrasi dengan peta lokasi pernikahan setelah alamat sudah ditentukan. Hapus catatan placeholder setelah informasi final diisi.
